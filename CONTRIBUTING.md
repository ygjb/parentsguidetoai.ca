# Contributing

Thank you for helping make this guide more accurate and useful for B.C. families.

## How to provide feedback or report issues

This project uses **GitHub Issues** for all feedback, corrections, and suggestions.

**[Open an issue](../../issues/new)**

---

## What to report

Please use GitHub Issues for:

- **Broken or outdated links** — resource pages move; if a link 404s or redirects somewhere unexpected, please report it
- **Factual errors** — incorrect information about AI tools, school policies, B.C. laws, or contact resources
- **Outdated information** — policies, services, and laws referenced in this guide can change; flag anything that no longer reflects current reality
- **Accessibility concerns** — problems with readability, contrast, screen reader compatibility, or keyboard navigation
- **Missing resources** — relevant Canadian or B.C.-specific resources that should be included
- **Clarity and language** — sections that are confusing, use unnecessary jargon, or could be explained more plainly
- **Typos and grammar** — small corrections are welcome

## What to include in your issue

A useful issue includes:

1. A clear description of the problem or suggestion
2. The section or URL where the issue appears (e.g., "Section 7 — Risks, Deepfakes accordion" or "Resources — Online Safety links")
3. What you expected to see, and what you saw instead (for errors)
4. A suggested correction or improvement, if you have one

## What this project does not accept

- Pull requests that change substantive content without prior discussion in an issue
- Requests to add commercial products, services, or promotional content
- Content that contradicts the guide's plain-language, non-partisan approach

## Scope

This guide is specifically written for **B.C. families** and focuses on the B.C. and Canadian legal and support landscape. Suggestions that are relevant only to other jurisdictions are outside scope, though feedback that improves clarity for all readers is always welcome.
